# Skills

A collection of agent skills for [skills.sh](https://skills.sh/).

## Install

```bash
# Install all skills
npx skills add zupolgec/skills --all

# Install a specific skill
npx skills add zupolgec/skills@skill-name
```

## Skills

| Skill | Description |
|-------|-------------|
| [qontoctl](qontoctl/) | Manage Qonto business banking — accounts, transactions, transfers, invoices, quotes, and more |
| [unifi](unifi/) | Manage UniFi Network consoles — devices, clients, networks, WiFi, firewall, NAT and port forwarding — via the official API and restish |

## Creating a new skill

```bash
npx skills init skill-name
```

Then move the generated directory into this repo.
